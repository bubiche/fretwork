# classical_guitar.sf2 — "Spanish classical guitar" (FreePats)

Sampled by Roberto for the FreePats project (recorded 2008, released June 2019).
Source: https://freepats.zenvoid.org/Guitar/acoustic-guitar.html

License: Creative Commons CC0 1.0 public domain dedication
(https://creativecommons.org/publicdomain/zero/1.0/). Attribution is not
required by the license; credit given with thanks.

The file is shipped byte-identical to the FreePats distribution (a single preset
at bank 0, program 0). The app clones that preset onto the GM guitar programs
in memory at load time — see `src/alphatab/sf2.ts`.

(The sibling `README.md` and `LICENSE` in this directory describe the SONiVOX
GM bank and are kept verbatim as distributed.)
